# Hello World Java Programs

This repository contains two simple Java programs that print "Hello World" to the console.

## Files

- `HelloWorld.java`: A simple Java class with a main method that prints "Hello World"
- `HelloWorldApp.java`: An alternative implementation that also prints "Hello World"
- `HelloWorldTest.java`: A test class that verifies both implementations work correctly

## How to Compile

To compile all Java files in this repository:

```bash
javac *.java
```

## How to Run

To run the first Hello World program:

```bash
java HelloWorld
```

To run the second Hello World program:

```bash
java HelloWorldApp
```

To run the tests:

```bash
java HelloWorldTest
```

## Expected Output

When running either `HelloWorld` or `HelloWorldApp`, you should see:

```
Hello World
```

When running the tests, you should see:

```
HelloWorld test: PASSED
HelloWorldApp test: PASSED
All tests passed successfully!
```
